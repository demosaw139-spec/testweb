# Orbit job portal — frontend preview

This is a dependency-free, responsive frontend concept for the Orbit job portal. It is a static browser experience; it does not include a backend, authentication, persistent saved jobs, or real job application and newsletter submission.

## Run locally

Open `index.html` in a modern browser. No package installation or build step is required. An internet connection is only needed for the optional DM Sans and Manrope fonts; the page has system fallbacks.

## Included interactions

- Search featured roles by keyword and location, browse the remote/design/engineering categories, and sort by newest or salary.
- Save and unsave roles for the current page view.
- Open an application form and submit a local preview without transmitting or storing the entered information.
- Use responsive navigation, category shortcuts, and the email signup preview.
- Explore the globe illustration, which has a subtle pointer response and respects reduced-motion preferences.

Job listings and company marks are illustrative sample content. Connect these controls to the planned Django services before using the experience with real users or applicant information.
